## Context

GSC organic clicks fell to 6,200 (Aug 17–Sep 13) from 7,523 (Jul 20–Aug 16), −17.6%; the homepage lost 941 clicks and the flagship lost 666, partly offset by gainers, so no sitewide collapse is established. The latest GSC export ends September 13. Local Lighthouse 12.8.2 mobile median is 76 with simulated LCP 4.54s; two cold samples show TTFB at 81–86% of observed LCP while the hero image loaded in 28–119ms. The PageSpeed API returned a 429, so no Google-hosted score exists, and this is lab evidence — it does not prove performance caused the search decline. Field review of the 114 affected URLs (rolling validation started September 8) is due around October 6.

The business outcome is qualified organic visitors, not payment conversion. Revenue owns paid-event and attribution definitions; this PRD consumes verified paid attribution only when available and otherwise stays independent.

No title/H1 edit, no traffic claim. Publication is João's owner action through the existing blog workflow. If the served source is a production DB record, the exact existing repository backup gate must run before any content write: `yarn db:backup` → `yarn db:backups` → `gzip -t` on both new archives, recording their paths before the write; stop if it fails. No backup is taken now and no surplus gate is added.
3. **Mobile origin/HTML cache.** Diagnose the already-observed variance with bounded request/header/cache evidence per the mobile LCP plan's measurement method; reuse the existing three-run baseline and do not repeat it. A change is justified only if the variance reproduces **and** its cause is established — reproduced variance alone is not enough. Any header change must preserve variant isolation and must not let public HTML cache authenticated or user-specific content.
4. **Optional Three Kings test (not required).** No eligible high-volume candidate exists. Only if selected Sep 18–22 after higher priorities: the report's exact `/blog/what-resolution-for-print` intro — answer-first 300/150 PPI pixel dimensions, not just the DPI→PPI wording — see the [report section](../SEO/reports/2026-09-16-search-traffic-action-plan.md#three-kings-short), stable title/H1, and a post-crawl verdict; otherwise it stays unselected with no closure obligation.
5. **Outcome decision.** Only after João authorizes a production rollout of an actual change, three new comparable production mobile runs on the same production URL/environment/method as the reused baseline are compared against the lab median; if a header changed, the authenticated-vs-public cache regression test is included. A separate preview performance baseline remains optional; a proposed cache change first needs representative-preview variant-isolation evidence under AC-4. ≤2.5s is an operational lab target, not guaranteed closure (field uses p75); the AC records the honest retain/revert/stop result. If the variance does not reproduce, document the STOP path with no new runs or deployment. If variance reproduces but the cause remains unproven, keep AC-4 PARTIAL and defer the change.

Deliverable acceptance is separate from business success: a traffic rebound is a monitored outcome, not an AC (−17.6% is not a promise), and a failed experiment with a documented stop decision closes its experiment AC.
