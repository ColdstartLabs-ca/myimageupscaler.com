## How to run a fair bulk comparison

Use the same source files and output convention for every future candidate. Record the tool or model version, plan or trial limits, settings, input and output dimensions, format, watermark state, processing time, and per-file success or failure. A comparison is not reproducible if the model, hardware, crop, or sample changes between rows.

Keep a manifest with the original filename, output filename, candidate, version, settings, and result status. Write outputs to a new directory so a failed run cannot silently replace the originals. Review one small group before processing the full catalog, then retry only failed files.

For JPEG-heavy catalogs, the [JPEG upscaling guide](/formats/upscale-jpeg-images) covers source artifacts to check before enlargement. For larger deliverables, use the [4K upscaling guide](/scale/upscale-to-4k) to choose a target size instead of enlarging every file by habit. The [e-commerce product-photo workflow](/use-cases/ecommerce-product-photos) adds catalog-specific checks for labels, crops, and consistent presentation.

## What this result does and does not answer

This record answers a narrow question: can the installed Sharp pipeline repeat a documented 2x WebP resize across four representative inputs? Yes—the output dimensions and files are recorded above.

It does not answer which AI model creates the most believable detail, which hosted service has the fastest queue, whether a plan allows a particular batch size, or how another candidate handles watermarks. Those claims require a new run on the same inputs and a dated record. No such run was performed here.

For a production catalog, treat the local result as a baseline, not a recommendation to process everything immediately. Compare the first approved sample with the original, check text and edges at full size, and retain a rollback path.

## Final recommendation

Choose the workflow that passes your own controlled sample and can explain its failures. Sharp 0.34.5 is the tested option in this local artifact for deterministic scripted resizing; it should not be presented as an AI upscaler or as a universal winner. For recurring work, repeat the four-input record whenever the tool, model, plan, settings, or source catalog changes.
